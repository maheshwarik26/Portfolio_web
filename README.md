Portfolio Website

A MERN portfolio built with React, Express, MongoDB, and Framer Motion.

Features:
- Responsive portfolio UI
- Animated sections
- Contact form connected to backend
- Projects fetched from MongoDB
- Skills filtering
- Interactive About and Skills sections

Tech Stack:
Frontend: React, CSS, Framer Motion, Axios
Backend: Node.js, Express.js, MongoDB, Mongoose
Tools: Git, GitHub, Postman

How to Run:
frontend -> npm install -> npm run dev
backend -> npm install -> npm run dev
